# Privacy Policy — ShipCheck

Last updated: 15 November 2026

ShipCheck is a Forge app for Jira, built by Hardi24 for the Codegeist 2026 hackathon. It helps release managers decide whether a Jira release is ready to ship.

## What ShipCheck does with your data

- ShipCheck reads Jira data (projects, versions, issues, assignees) and Atlassian Teamwork Graph data (goals, teams) **only to compute a release readiness score and show it inside Jira**.
- It does **not store** any personal data. It does not use a database, cookies, or tracking. Scores are computed in memory and shown in the Jira UI; nothing is written to any storage.
- It does **not send data to any third party**. All processing happens on Atlassian Forge infrastructure. The app makes no external network requests.
- Names of issue assignees and owners are displayed inside Jira as part of the readiness evidence (for example, who owns an open blocker). They are not copied, exported, or shared anywhere else.
